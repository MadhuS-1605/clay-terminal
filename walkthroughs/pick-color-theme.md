# Pick a Color Variant

Clay Terminal ships four color variants sharing the same coral/warm-gray
palette:

- **Clay Terminal** — dark, near-black warm background
- **Clay Terminal Light** — light, warm off-white background
- **Clay Terminal High Contrast** / **Clay Terminal Light High Contrast**
  — accessibility-focused, stronger borders and higher-contrast text
