# Set File Icon Theme

Clay Terminal Icons is a themed file icon set (100+ languages and file
types) bundled in this same extension — but VS Code only applies the
**color** theme automatically on install. The file icon theme is a
separate picker.

```button
{"title": "Set File Icon Theme", "command": "workbench.action.selectIconTheme"}
```

Pick **Clay Terminal Icons** from the list that opens.
